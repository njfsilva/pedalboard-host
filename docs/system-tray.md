# Run from the system tray

The tray icon keeps audio and MIDI/OSC controls running while the main window is hidden.

On a fresh install, the main window opens and the tray icon appears. With the icon active:

- Closing the main window or choosing **File → Exit** hides the window. Audio and controller mappings keep running.
- Double-click the icon to show or hide the window.
- To exit the host, right-click the icon and choose **Quit**. The host prompts you to save any unsaved patch changes.

The icon returns automatically when Windows Explorer restarts.

## Start hidden

To launch with the window hidden, enable **Start in tray** under **Options → Misc Settings** with **Display tray icon** enabled.

## Desktop windows

Settings, the patch organiser and processor editors can be placed outside the main window. They hide and return with the main window, and share its taskbar button.
